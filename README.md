# عمار — سوق مواد البناء (نسخة ثابتة)

صفحة رئيسية ثابتة (HTML/CSS/JS فقط) لمنصة **عمار** لبيع مواد البناء، مبنية بالكامل بالعربية مع دعم RTL، ومستوحاة بصريًا من النظام التصميمي لموقع [ثمانية](https://company.thmanyah.com/): خط IBM Plex Sans Arabic، مساحات بيضاء واسعة، درجات محايدة دافئة، وأسلوب تحريري هادئ، مدموجة مع هوية عمار (كحلي + ذهبي).

## هيكل الملفات

```
ammar-site/
├── index.html          # الصفحة الرئيسية (كل الأقسام)
├── css/
│   └── style.css       # النظام التصميمي كاملًا (متغيرات CSS + استجابة)
├── js/
│   └── main.js         # البيانات التجريبية + التفاعلات (سلة، مفضلة، سلايدر، قائمة جوال)
├── assets/
│   └── images/         # صور مولّدة للأقسام والمنتجات والبانرات والشعار
└── .nojekyll           # لتوافق GitHub Pages
```

## أقسام الصفحة (بترتيب التصميم المرجعي)

1. شريط تنقل علوي مثبّت (شعار، روابط، سلة، تسجيل دخول/إنشاء حساب)
2. قسم البطل مع شريط بحث وقائمة أقسام
3. صف أيقونات المزايا (جودة، توصيل، أسعار، دعم)
4. شبكة الفئات الست
5. بانران ترويجيان (توصيل سريع / توريد لمشاريعك)
6. شبكة المنتجات المميزة بأسعار بالريال السعودي مع سلايدر
7. شريط شعارات الشركاء
8. شريط الثقة الداكن قبل التذييل
9. التذييل

## الدمج مع المستودع الحالي

الموقع ثابت بالكامل (لا يوجد باكند أو قاعدة بيانات) ويستخدم مسارات نسبية، لذا يعمل مباشرة على GitHub Pages تحت أي مسار فرعي مثل `/ammar-building-materials/`.

لأن المستودع الحالي يبني تطبيق React عبر GitHub Actions، عند الدمج اختر أحد الخيارين:

- **استبدال كامل (الأبسط):** انسخ `index.html` و`css/` و`js/` و`assets/` و`.nojekyll` إلى جذر المستودع، واحذف أو عطّل خطوة البناء في `.github/workflows/deploy.yml` بحيث ينشر Pages من الجذر مباشرة (أو من فرع `gh-pages` بعد نسخ الملفات إليه).
- **مجلد فرعي:** ضع الملفات في مجلد مثل `static/` وانشرها كموقع منفصل أو وجّه إليها من التطبيق.

## ملاحظات

- كل البيانات (المنتجات، الأسعار، الشركاء) تجريبية داخل `js/main.js` ويمكن تعديلها بسهولة.
- الأسعار بالريال السعودي (ر.س) بقيم واقعية للسوق السعودي.
- لا توجد أي اعتماديات خارجية سوى خط Google Fonts (IBM Plex Sans Arabic).

## إعادة الهيكلة (تحديث الهوية)

- **`buyer-home.html`** أصبحت الواجهة الرئيسية للمنصة: سوق فعلي قابل للتصفح والشراء (بحث ذكي، اختيار مدينة التوصيل، Mega Menu للتصنيفات، درج سلة جانبي مع الضريبة والتوصيل وتنبيه تعدد الموردين، أقسام: مقترح لك، عروض اليوم، الأكثر طلبًا في مدينتك، اشترِ بالجملة، موردون موثوقون، تجميعات المشاريع، شاهدتها مؤخرًا).
- **`index.html`** تحولت إلى بوابة **«عمّار أعمال»** الموجهة للموردين والمقاولين والشركات، مع CTA رئيسي «سجّل كمورد» وثانوي «ادخل إلى المتجر» → `buyer-home.html`.
- **`css/ammar-theme.css`** طبقة الهوية الموحّدة بألوان عمّار الأصلية عبر كل الصفحات: تركواز الشعار ‎#00a8cc / #0086a8‎ وبرتقالي الطوب ‎#e76f51‎ (نفس ثيم صفحة عمّار أعمال)، خط IBM Plex Sans Arabic، بأسلوب مسطح وبسيط تُحمَّل بعد بقية الأوراق في كل الصفحات، وتضم مكونات المتجر الجديدة وشارات الحالة ووحدة السعر وشرائح الكمية بأسلوب مسطح ومحايد.
- المنطق القائم في `store.js` و`buyer.js` لم يُمس؛ الإضافات في `buyer-ui.js` (مدينة التوصيل `ammar_buyer_city`، سعر الجملة المشتق، وقت التوصيل، درج السلة) قابلة للاستبدال بباكند حقيقي لاحقًا.

- **فصل تجربة المتجر عن بوابة المشتري أعمال**: صفحة مفضلة مستقلة للمتجر `favorites.html` (أيقونة القلب في هيدر المتجر تقود إليها)، والسلة عبر `buyer-cart.html` ودرج السلة، بينما تبقى صفحات البوابة (`buyer-wishlist.html` وأخواتها) لتجربة الأعمال.
- **شعارات الموردين**: ضع الشعارات الرسمية في `assets/images/suppliers/` بالأسماء الموثقة في `README.txt` داخل المجلد وستظهر تلقائياً بمقاس موحّد، مع مونوغرام بديل تلقائي عند غياب الملف.
